# Direction: a world worth returning to

Mineworld should become a beautiful, tactile, solitary VR exploration/building game. Minecraft's readable voxel interactions are the starting vocabulary; the setting, progression, creatures, discoveries, and reasons to build should find their own identity.

## Skyreach

The first place is an archipelago suspended over a cloud sea. Cedar groves shelter pale springs. Buried deepstone sits beneath softer limestone and soil. Old arches, resonators, forges, and waystones suggest that these islands once formed a connected network. Warm daylight, a ringed planet, greenery, and useful empty space make building a home appealing.

The normal player experience is **Journey mode**, not an unrestricted sandbox. The loop is: explore, gather finite materials, shape the landscape, build from what you have earned, restore old structures, gain a capability, and use that capability to reach somewhere that changes the next problem. Creative mode remains useful for development and free building, but it should not determine progression design.

The current progression spine is deliberately physical rather than menu-driven: **First Light → Old Arch → Lumen Hollow → The Old Quarry**. First Light teaches gathering and deliberate tool crafting. Lumen Hollow asks the player to spread out across an island, feed three resonators, temper the tool, and dig down for deepstone. Deepstone then changes the forge itself into the passage to The Old Quarry. Each discovered destination should retain a persistent route back rather than behaving like a disposable level entrance.

The Old Quarry should become the next substantial gameplay beat. Deepstone needs a meaningful downstream use there—restoring machinery, opening a buried structure, powering an original traversal device, or another mechanic that clearly changes what the player can do. The solution should use the space and the player's hands rather than defaulting to an inventory menu.

## Development priorities

1. Make headset movement, targeting, reach, portal arrivals, landmark scale, and sustained Quest 3 performance reliable.
2. Turn voxel interaction into a satisfying game economy: gathering, finite inventory, tools, useful crafting, and meaningful building choices.
3. Give every major destination a distinct physical interaction or capability gain rather than only a new resource colour.
4. Preserve strong outward and return motivations: discovery should pull the player away from home while building, persistent routes, and accumulated utility give them reasons to come back.
5. Add threats and creatures only when they reinforce exploration and inhabiting the world rather than turning Mineworld into a generic combat game.
6. Expand world generation and content only as far as persistence and performance support.

Prefer one complete loop over a menu full of unfinished systems. Freeform building matters, but it should live inside a game with goals, scarcity, discovery, capability changes, and progression.

## Guardrails

- Quest 3 is the principal device. Headset rendering and input determine whether something is ready.
- Keep the product focused on VR. Desktop input is an opt-in development tool for checking shared world behavior without a headset. There are no phone gameplay controls.
- Stay original: no copied textures, sounds, names, UI, or creature designs.
- Existing player builds should survive updates. Generator version 1 is a compatibility contract until an explicit migration path exists.
- Prefer lightweight scene props and state changes over rewriting old terrain merely to add progression content.
- Preserve the GitHub Pages workflow and the stable play link.
- Document measurable validation separately from aesthetic judgment and untested assumptions.
